# Sprint 3 Review (W9–W10)

## Sprint Goal

Deliver and demonstrate user profile management, completed trails tracking, interactive map updates with live user GPS location, safety tips, trail sharing, admin user suspension, and final end-to-end testing.

## Completed Work

- Completed trails tracking (`US-16`, `feature/completed-trails`, `feature/my-trails`) was implemented so users can log and view finished hikes.
- User profile and account editing (`US-17`, `feature/profile`) was implemented with persistent updates.
- Trail safety guidelines (`US-18`, `feature/trail-moredetails`) and native trail link sharing (`US-19`) were integrated into trail details pages.
- Interactive maps displaying the user's current real-time location (`US-22`, `feature/maps-v2`) were implemented.
- Admin user account suspension (`feature/admin-dashboard`, `feature/admin-api`) was implemented to block login access for suspended accounts.
- Automated frontend tests (`feature/frontend-tests`), final bug fixes (`fix`), and full end-to-end verification across `US-01` to `US-22` were completed and merged int `develop` .
